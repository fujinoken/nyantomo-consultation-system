# にゃんとも相談管理システム Ver1.1

## 概要
Streamlit + Excel保存で動く、にゃんとも事業用の相談管理アプリです。

## ファイル
- app.py
- requirements.txt

## 起動方法
```bash
streamlit run app.py
```

## GitHub / Streamlit Cloud
GitHubに app.py と requirements.txt をアップロードし、Streamlit Cloudで app.py を指定してデプロイします。
